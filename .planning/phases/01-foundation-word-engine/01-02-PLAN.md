<objective>
Build the word engine: dictionary loading with module-exact validity, an anagram-class trie for sub-word enumeration, the module-exact sim word chooser, and optimal / fast word packing (choose disjoint dictionary words from a rack maximizing total reward). This is the hottest code path of the bot (Monte Carlo valuation calls the packer hundreds of times per 1-second auction), so performance is a first-class requirement.
Output: `src/engine/*`, tests, `scripts/bench-engine.ts` (run with `npx tsx scripts/bench-engine.ts`).
</objective>

// spacetimedb/src/dictionary.ts
lexWords()      = WORDLIST.split("\n").filter(l => l.length > 0)        // file order (already sorted)
wordsByLength() = [...lexWords()].sort((a,b) => b.length - a.length || (a < b ? -1 : a > b ? 1 : 0))
isValidWord(word): target = asciiUppercase(word); if byteLength(target) < 2 return false;
                   if !isAsciiUppercase(target) return false; binary search lexWords() for target
findBestPlayable(rack: Map<letter,count>, minLen): total = sum counts; if total < minLen return undefined;
   for word of wordsByLength(): if word.length < minLen break; if word.length > total continue;
       if every letter count of word <= rack count: return word
   return undefined
// reward: floor(sum(VALUE) * num / den), mult by length 1,1,1.5,2,2.5,3(7+)

<task type="auto">
  <name>Task 3: Packer (exact + fast) with memo</name>
  <files>src/engine/packer.ts, src/engine/index.ts, test/engine/packer.test.ts</files>
  <action>
  Problem: choose a multiset of dictionary words whose combined letters ⊆ rack, maximizing Σ reward (reward depends only on the class). Letters may be left unused.
  `class Packer { constructor(index, {cacheSize?: number}); packExact(rack, {minLen?, nodeLimit?, timeLimitMs?}): PackResult; packFast(rack, {minLen?}): PackResult; value(rack): number }`
  `PackResult = { score: number; words: string[]; classIds: number[]; exact: boolean; nodes: number }` — words are submittable strings (class representatives), playable sequentially from the rack.
  Exact: depth-first branch & bound with canonical pivot branching (pick a pivot letter still in the rack; branch: pivot unused (remove one copy) OR each fitting class containing the pivot), upper bound = floor(3 × face value of remaining tiles) (tighten if you can, e.g. per-letter max achievable multiplier, rack size < 7 caps mult at mult(size)), memoize exact sub-results by rackKey in a bounded LRU (Map insertion-order eviction), incumbent from packFast for early pruning, stop early when incumbent == upper bound. If nodeLimit/timeLimit hit: return best found with exact=false.
  Fast: high-quality approximate (e.g. greedy over classes by reward with a small beam / limited branching on the pivot) targeting mean < 0.3 ms on 20-tile racks and small average gap vs exact. Document the algorithm.
  Engine barrel `src/engine/index.ts` exports everything plus a lazily-built shared default `getEngine()` = {dict, index, packer} singleton.
  Bench `scripts/bench-engine.ts`: seeded random racks from the bag distribution (sizes 12, 20, 25, 30, 35); report enumeration p50/p99, packExact p50/p99/exact-rate, packFast mean and mean/max gap vs exact, dictionary build time and memory (process.memoryUsage).
