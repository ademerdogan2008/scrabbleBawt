Game facts: each player starts with `startingRackSize` hidden tiles and balance `startingBalance`; one letter per auction; Vickrey/FirstPrice payment `paid` is deducted from the winner; unbid auctions (winnerId null) consume the letter; word rewards add to both balance and score; the auction with remainingAfter == 0 is the last.

  `new MatchTracker(config: MatchConfig, myStartRack: Rack)`; methods:
  - `auctionOpen(info: AuctionInfo)` — sets current; the open letter counts as seen (removed from unseen).
  - `auctionResult(o: AuctionOutcome)` — append history; clear current if it matches; if winnerId != null: winner.won[letter]++, lettersWon++, balance -= paid, totalPaid += paid; if winner is me: rack[letter]++. auctionsDone++.
  - `wordPlay(ev: WordPlayEvent)` — append; player.played += letters; balance += reward; score += reward; for opponents: for each letter, excess = need - (won + revealedHidden - played_before) > 0 ⇒ revealedHidden += excess (cap total at startingRackSize; if exceeded, record an inconsistency counter and clamp); for me: rack -= letters (throw if impossible — indicates a bug).
  - `setBalance(id, balance, score)` — authoritative resync from live rows; count discrepancies in `diagnostics`.
  - `setMyRack(rack)` — authoritative resync; count discrepancies.
  - `view: MatchView` getter (maintained incrementally; cheap) and `snapshot(): MatchView` (deep copy).
  - Derived per player: knownHeld = won + revealedHidden - played (never negative), hiddenUnknown = startingRackSize - total(revealedHidden).
  - unseen = BAG - myStartRack - every auctioned letter (closed + current open) - Σ_opp revealedHidden (never negative; if negative ⇒ diagnostics).
  - `bagRemaining` helper: current ? current.remainingAfter : totalAuctions - auctionsDone (document); `auctionsRemaining` = totalAuctions - auctionsDone.
  - `diagnostics: { balanceMismatches, rackMismatches, hiddenOverflow, unseenNegative }`.
  view.ts: helper functions over a MatchView (e.g. `leader(view)`, `scoreGapToLeader(view)`, `maxOpponentBalance(view)`, `isLastAuction(auction)`, `opponentById`). Re-export the core view interfaces.
