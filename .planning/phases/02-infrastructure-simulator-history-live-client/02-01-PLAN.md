<task type="auto">
  <name>Task 1: Match engine (src/sim/match.ts)</name>
  <files>src/sim/match.ts, src/sim/rngStreams.ts, src/sim/index.ts, test/sim/match.test.ts</files>
  <action>
  `runMatch(spec: Partial<MatchSpec>, seats: SeatSpec[], seed: number): MatchResult`.
  MatchSpec: auctionType ('Vickrey'), auctionDurationMs (1000), startingRackSize (5), startingBalance (100), decisionBudgetMs (250), enforceBudget (false; when true a decide() slower than auctionDurationMs - simulatedLatencyMs voids that decision), simulatedLatencyMs (60), trace (false), matchId.
  SeatSpec: {id, name, kind:'policy', policy} | {id, name, kind:'sim', simStrategy}.
  RNG: independent streams from the seed — bagRng (deal + draws), simRng (one int(-2,2) per sim per auction open, in seat order, ALWAYS consumed even if the sim is broke), tieRng (module shuffle of positive bids, n-1 calls), and per-policy-seat rng = new Rng(hashSeed(seed,'seat',index)). Consequence: deal and letter sequence are independent of decisions (perfect pairing).
  Flow per RULES.md: deal startingRackSize per seat in seat order via drawLetter (uniform index over A..Z-sorted remaining counts); draw first letter; open auction 0 (index = round-1, remainingAfter = tiles left in bag); sims bid at open (simBid with jitter; skip if <= 0); every policy seat: decide(view, auction, ctx) on the same pre-decision state (simultaneous), then apply each seat's words in seat order (dictionary-valid + rack-feasible else count rejectedWords and skip; reward to balance & score; emit word event to ALL trackers) then its bid (reject + count if bid > balance or not an integer >= 0); close: bids > 0 in order [sims in seat order, then policies in seat order], tieRng shuffle, stable sort desc, winner/paid (Vickrey: second ?? min(1, top); FirstPrice: top), balance check, award letter; emit result to all trackers; if a sim won: sim plays findBestPlayable(rack, 3) (one word) and emit it; draw next letter or end. Words are impossible after the final close.
  Trackers: one MatchTracker per policy seat with its own start rack; call policy.onMatchStart / onAuctionClosed / onMatchEnd at the right points.
  MatchResult: seed, auctions, per seat {id, name, kind, score, balance, rank (1 + #strictly higher), win (score == max), lettersWon, totalPaid, wordsPlayed, words[], unplayedTiles, unplayedValue, rejectedWords, rejectedBids, voidedDecisions, decideMs {n, mean, p50, p99, max}}, winnerIds, and optional trace {auctions:[{index, letter, bids:{seatId:amount}, winnerId, paid, top}], words:[{index, seatId, word, reward}], finalRacks}.
  Tests (scenario-level, deterministic): Vickrey payment incl. sole bidder pays 1; FirstPrice pays top; ties resolved randomly (both outcomes occur over seeds); unbid letter consumed (auction count stays 98-5N); final letter can never be used by policies but can be by sims; sim bids exactly simBid; sim plays only after a win, one word, min length 3, module choice; invalid words / over-balance bids rejected without effect; same seed => identical letter sequence for different policies; N = 2..12 and rack sizes 0..8 work; balances never negative; score == Σ rewards.
  </action>
  <verify>npx vitest run test/sim</verify>
  <done>match engine passes conformance tests</done>
</task>

  <action>
  Baselines (each a PolicyFactory):
  - `starter`: exact port of the official bot-starter: bid = min(have==0 ? value+2 : max(1,value), max(0,balance)); words: at most ONE word per decide when the rack changed since the last decide (its 500 ms debounce means one attempt per rack-change event), chosen as the longest playable word with length >= 2, ties lexicographically smallest (= findBestPlayable(rack, 2)).
  - `greedy`: bids round(1.5×value + 2) capped at balance; plays words greedily every decide (repeat bestSingleWord by reward while one exists).
  - `hoarder`: bids round(2.2×value + 3) (×1.6 in the last third); plays nothing until remainingAfter <= 1, then plays packExact(rack).words.
  - `random`: uniform bid 0..min(balance, 3×value+5) via ctx.rng; plays a random valid word sometimes.
  Registry: `createPolicy(spec: string, seed): Policy` with spec grammar `name` or `name:{json params}`; `sim:<Strategy>` handled by the simulator as a sim seat (registry exposes `parseSeat(spec)` returning SeatSpec without id). The registry imports `./baselines/index.ts`, `./bawt/index.ts`, `./clones/index.ts`, `./tricks/index.ts`; create the latter three as stubs exporting `export const policies: Record<string, PolicyFactory> = {}` so later plans only edit their own directory index.
