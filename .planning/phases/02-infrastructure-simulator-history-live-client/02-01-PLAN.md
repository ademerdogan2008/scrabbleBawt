  `runMatch(spec: Partial<MatchSpec>, seats: SeatSpec[], seed: number): MatchResult`.
  MatchSpec: auctionType ('Vickrey'), auctionDurationMs (1000), startingRackSize (5), startingBalance (100), decisionBudgetMs (250), enforceBudget (false; when true a decide() slower than auctionDurationMs - simulatedLatencyMs voids that decision), simulatedLatencyMs (60), trace (false), matchId.   SeatSpec: {id, name, kind:'policy', policy, oracle?: boolean} | {id, name, kind:'sim', simStrategy}. Oracle seats (threat modelling of RNG-exploiting rivals) get `policy.onOracle?.(trueRacks)` with a snapshot of every seat's true rack right before each decide().
  Structure for reuse by hostReplay (Task 4): export the step functions `drawLetter`, `closeAuction` (bid filter > 0, shuffle, stable sort desc, winner/paid, balance check), `awardLetter`, `simWordPlay` (findBestPlayable(rack, 3)) and an internal `runMatchCore(spec, seats, source: MatchRngSource, bidOrder: BidOrderModel)`. MatchRngSource = {deal, draw, simJitter, tieShuffle}; BidOrderModel decides the pre-shuffle order of positive bids. runMatch passes the independent streams (below) and the order [sims in seat order, then policies in seat order]; hostReplay passes the host RNG and the RULES §4.3 swap_remove/push order model.
  RNG (runMatch): independent streams from the seed — bagRng (deal + draws), simRng (one int(-2,2) per sim per auction open, in seat order, ALWAYS consumed even if the sim is broke), tieRng (module shuffle of positive bids, n-1 calls), and per-policy-seat rng = new Rng(hashSeed(seed,'seat',index)). Consequence: deal and letter sequence are independent of decisions (perfect pairing).
  Flow per RULES.md: deal startingRackSize per seat in seat order via drawLetter (uniform index over A..Z-sorted remaining counts); draw first letter; open auction 0 (index = round-1, remainingAfter = tiles left in bag); sims bid at open (simBid with jitter; skip if <= 0); every policy seat: decide(view, auction, ctx) on the same pre-decision state (simultaneous; ctx.netRttMs = simulatedLatencyMs), then apply each seat's words in seat order (dictionary-valid + rack-feasible else count rejectedWords and skip; reward to balance & score; emit word event to ALL trackers) then its bid (reject + count if bid > balance or not an integer >= 0); close via closeAuction (Vickrey: second ?? min(1, top); FirstPrice: top), awardLetter; emit result to all trackers; if a sim won: simWordPlay (one word) and emit it with auctionIndex = index of the auction that just closed; draw next letter or end. Words are impossible after the final close.
  Trackers (STATE-02): one MatchTracker per policy seat with its own start rack. Feed each tracker ONLY via applyEvent(tracker, e: MatchEvent) from src/state/events.ts: 'start' (MatchConfig with myId = seat id, players in seat order, totalAuctions = 98 − rack·N), 'open' with AuctionInfo {auctionId: index+1, index, letter, opensAtMs: index*(auctionDurationMs+1.5), closesAtMs: opensAtMs+auctionDurationMs, remainingAfter}, 'result', 'word'. Call policy.onMatchStart / onAuctionClosed / onMatchEnd at the right points. With trace=true, MatchResult.trace.events[seatId] holds that seat's MatchEvent[].
  MatchResult: seed, auctions, per seat {id, name, kind, score, balance, rank (1 + #strictly higher), win (score == max), lettersWon, totalPaid, wordsPlayed, words[], unplayedTiles, unplayedValue, rejectedWords, rejectedBids, voidedDecisions, decideMs {n, mean, p50, p99, max}}, winnerIds, and optional trace {auctions:[{index, letter, bids:{seatId:amount}, winnerId, paid, top}], words:[{index, seatId, word, reward}], finalRacks, events}.
  src/sim/index.ts re-exports match/tournament/stats only; it must NOT re-export hostRng or hostReplay (fair-play guard, see Task 4).
  Tests (scenario-level, deterministic): Vickrey payment incl. sole bidder pays 1; FirstPrice pays top; ties resolved randomly (both outcomes occur over seeds); unbid letter consumed (auction count stays 98-5N); final letter can never be used by policies but can be by sims; sim bids exactly simBid; sim plays only after a win, one word, min length 3, module choice; invalid words / over-balance bids rejected without effect; same seed => identical letter sequence for different policies; N = 2..12 and rack sizes 0..8 work; N*rack >= 98 throws; balances never negative; score == Σ rewards; trace.events[seat] replayed with replay(events) deep-equals that seat's live tracker view.
