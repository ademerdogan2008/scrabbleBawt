<task type="auto">
  <name>Task 2: Valuation, λ pacing, bidding, words, endgame, objective</name>
  <files>src/bots/bawt/{valuation,lambda,bidding,words,endgame,objective,index}.ts, test/bots/bawt.test.ts</files>
  <action>
  valuation.ts: scenarios = S random completions of the future from MatchView.unseen (shuffle unseen; first bagRemaining tiles = future auctions; rest = rivals' hidden tiles) shared via common random numbers within a decision (seeded from ctx.rng). Future acquisitions F_s: walk the scenario's future letters; win a letter iff heuristic-value/λ > a field max-bid draw for that letter & phase and we can afford it (Vickrey: pay the draw) — this makes F budget-aware so money's value is captured; cap by params.maxWinShare × futureCount. V(R, B) = mean_s Pack(R ∪ F_s(B)). Marginal value of the open letter at price p: Δ(p) = V(R+L, B−p) − V(R, B) with CRN; break-even price p* = max p with Δ(p) >= 0 (bisection, few evaluations). Use packFast inside MC and packExact for small racks/final; memoize Pack by rackKey within the decision.
  lambda.ts: K-13-style pacing as a cross-check / quick path: λ (points per coin) by bisection so expected spend over remaining auctions at bids v_ℓ/λ equals balance + expected income (params.incomeRate), using the 26-letter value vector (cached per rack) weighted by unseen counts and the field model; lambdaScale by profile. Used for quick decisions and denial conversion.
  bidding.ts: Vickrey bid = min(balance, p* (or v/λ in quick mode) + denial adj); denial adj = min(params.maxOverbid, w_leader × rivalGain/λ) where rivalGain = cheap estimate of the letter's value to the rival closest in score above/below us (knownHeld + hidden expectation) and w from score proximity (normal density of projected gap); clamp at richest-relevant-rival balance + 1 (bidding more only leaks info); if every competitor's max possible bid is known (sims/broke) and below p*, bid that max + 1; focal points: if a strong rival has a modal cap (e.g. Bron 30 on JXQZ from profiles) and p* > cap, bid cap + 1; small symmetric noise (params.bidNoise, default ±5%) against valuation inversion; never bid on a letter with value <= 0 unless denial says so. FirstPrice: maximize E[(V-gain − b) · 1{M < b}] + ½·tie term over integer b ∈ [0, balance] using the field CDF.
  words.ts: candidates from packExact(R) (and best single words). Final flush handled in endgame. Mid-match cashing: for each candidate w (len >= params.minCashLen, default 7; shorter allowed when money-starved), compare on the SAME scenarios: play = r(w) + V(R−w, B+r(w)) vs hold = V(R, B); cash if play − hold > params.playMargin; up to 3 words per decision; never cash a word that uses the open auction's letter's best partners if the letter would extend it (Nijello rule: hold if the open letter completes a strictly better partition next round and we're likely to win it). Liquidity rule: if balance < params.minLiquidity and auctions remain > 8, allow cashing the best word regardless of length.
  endgame.ts: remainingAfter == 0 → words = packExact(R).words (time-limited exact; fallback packFast), bid = (any sim seated) ? balance : 0; remainingAfter == 1 → bid = balance (all-in; coins are worthless after), words: hold (flush next round) unless ctx.netRttMs > params.preFlushRttMs (then flush now); remainingAfter == 2 → values use k <= 1 future letter; ensure planned final packing is cached for instant flush.
  objective.ts: MatchKind/seat-aware weights — lobby & swiss: placement (denial weight on nearest rivals); bracket: minimize P(last) (risk-averse, weight on the rival just above last); final (2 seats, 3-game total score): pure expected own score (no denial); headsUp: drain-floor option (bid >= params.drainFloor × rival typical bid on letters we value at all).
  index.ts: createBawt(params) → Policy; anytime decide(): quick heuristic decision first, then MC refinement while ctx.now() < start + budgetMs − 3; deterministic. Export `policies` = { bawt, 'bawt-quick' (heuristic only), 'bawt-k13' (λ-only valuation) } for ablations.
  Tests: endgame rules; never-illegal decisions over 300 random matches vs mixed seats (simulator); determinism; budget respect; FirstPrice shading sanity (bid < value); denial cap respected.
